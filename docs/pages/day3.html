Day 3 · Build AI Agents

Agents that analyse data, combine tools, and work together.

Fri 13 Nov≈60 minutesPortal + optional Python
What we built live · agents for Serendib Bank (fictional): an analyst that writes and runs its own Python to find fraud patterns and draw charts, a home-loan advisor that combines documents, web search and calculation, an MCP tool added by URL, the same agent in code, and a workflow of agents with human approval.

Steps

  1. Transaction analyst (code interpreter)

    Create an agent, paste the analyst instructions, turn on code interpreter and attach transactions_oct2026.csv. Then ask:

    Which branches had the most disputed card transactions in October? Show me a bar chart.
    Look for anything unusual by time of day, country and merchant. What would a fraud analyst want to know?

    Open the code the agent wrote. Can you find both hidden patterns?

  2. Home-loan advisor (three tools)

    Create an agent with the loan advisor instructions and three tools: file search (the Day 2 PDFs), web search (or the rates bulletin 04-serendib-rates-bulletin.md if web search isn't available) and code interpreter. Ask:

    I earn LKR 450,000 a month after tax and my salary is credited to Serendib Bank. Can I afford a home loan of LKR 15 million over 20 years?

    Expected: about LKR 159,964 a month for the fixed period, under the LKR 180,000 limit (40% of income).

  3. Add a tool by URL (MCP)

    Add an MCP tool: label microsoft_learn, URL https://learn.microsoft.com/api/mcp. Ask:

    How do I add a custom blocklist to a guardrail in Microsoft Foundry?

  4. The same agent in code (optional, for developers)

    Open the repo in GitHub Codespaces or clone it, then:

    Terminal
    cd kit/day3
pip install -r requirements.txt
az login

    Copy .env.example to .env, add your project endpoint and model name, then run:

    Run
    python agent_app.py

    Watch the 🔧 tool: lines: the agent decides to call your Python functions. If something is wrong, the app tells you what to fix.

  5. A workflow of agents

    In Workflows, create a triage agent that hands over to a card agent or a loan agent, and add a human approval step before any refund. Try:

    I lost my card in Kandy yesterday and I see two withdrawals I didn't make.
🧪 Make it yours: give the analyst agent a CSV export from your own business (sales, tickets, orders, with no personal data) and ask it what a manager should worry about this month.
