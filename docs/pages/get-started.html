Get started

Azure access, a budget alert and your first Foundry project.

Before Day 1≈15 minutes
Before you start: everything in this kit is optional practice for after the live sessions. Today's demo costs a few cents in tokens, but always set a budget first.

1 · Get access to Azure

Most common

Your organisation's Azure

Ask your cloud or IT team for a resource group where you may create a Microsoft Foundry resource (Contributor on the resource group, plus a Foundry role on the project).

Personal

Azure free account

New accounts get free credit for the first 30 days, enough for this series. Sign up at azure.microsoft.com/free (a card is needed to verify identity).

Credits

Visual Studio or Microsoft for Startups

Visual Studio subscribers and Microsoft for Startups members receive monthly Azure credit, check your subscription benefits.

2 · Set a budget alert (2 minutes)

  1. Open Cost Management

    In the Azure portal search for Cost Management → Budgets → + Add.

  2. Create the budget

    Scope: your subscription or resource group. Amount: e.g. USD 10 per month. Add an email alert at 50% and 100%.

    Microsoft Learn: create a budget

3 · Create a Foundry project

  1. Open the Foundry portal

    Go to ai.azure.com and sign in with the same account.

  2. Create a project

    Choose Create project. Name it e.g. serendib-demo. Under advanced options pick the region Southeast Asia (or the region your organisation requires).

  3. Note two values

    On the project's Overview page copy the project endpoint (https://<resource>.services.ai.azure.com/api/projects/<project>). You'll need it for the code.

Can't create resources? That's a permissions question for your Azure administrator, share this page with them.
