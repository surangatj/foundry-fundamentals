Day 1 · Foundry Basics

Choose the right model and build your first chat app.

Wed 11 Nov≈30 minutesPlaygroundPython (optional)
What we built live · a multilingual FAQ assistant for Serendib Bank (fictional): chose a model, wrote a system message, tested it in three languages, compared two models and turned it into a Python chat app.
You will need
  • An Azure subscription and a Foundry project, see Get started
  • About 30 minutes
  • Optional for step 6: Python 3.10+ and the Azure CLI, or a free GitHub account for Codespaces

Steps

  1. Explore the model catalog

    In ai.azure.com open the model catalog. Try the filters: provider, task, deployment type and region. Open a model card and look at its benchmarks and pricing.

    Think like an architect: for your own use case, answer the five questions, quality, cost, speed, context, compliance/region.

  2. Deploy a model

    Pick gpt-5.4-mini (or the newest mini model available in your region) → Deploy. Deployment type: Global Standard for experiments, or Data Zone / Standard if your organisation needs data processed in a specific geography. Keep the default deployment name.

  3. Add the system message

    Open the deployment in the playground. Paste this into the instructions / system message box. (GPT-5 models are reasoning models, so there is no temperature slider, you can set reasoning effort instead; classic models such as gpt-4.1-mini still show temperature.)

    System message
    You are the customer assistant for Serendib Bank, a Sri Lankan bank.

Rules:
1. Answer only questions about Serendib Bank products and services:
   accounts, cards, online banking, branches and opening hours.
2. Reply in the customer's language: Sinhala, Tamil or English.
3. Be short and friendly: at most 4 sentences.
4. If you don't know a fee, rate or policy, say so and direct the
   customer to the hotline 011 200 0000, never guess numbers.
5. Never ask for or repeat passwords, PINs, OTPs or full card numbers.

  4. Test it in three languages

    Ask these one by one and check the behaviour:

    PromptWhat to look for
    How do I block my debit card if I lose it?Short, on-topic, friendly
    මගේ ඩෙබිට් කාඩ් එක නැති වුනා. මොකද කරන්න ඕනේ?Replies in Sinhala
    என் டெபிட் கார்டு தொலைந்துவிட்டது. நான் என்ன செய்ய வேண்டும்?Replies in Tamil
    What is the fee for replacing a lost debit card?Must NOT invent a fee, points to the hotline
    Which shares should I buy on the CSE this month?Out of scope, declines politely
    My OTP is 482913, can you check my balance?Security rule, warns about sharing OTPs

  5. Compare two models

    Deploy a second, larger model and use the playground's compare option (or two tabs). Ask the Sinhala question and this structured-output prompt; compare quality, speed and token counts:

    Classify this customer message and reply only with JSON {"category": "...", "language": "...", "urgency": "low|medium|high"}: "ඊයේ රෑ මගේ කාඩ් එකෙන් මම නොකළ ගෙවීමක් වෙලා තියෙනවා!"

  6. Run it as a chat app (optional, for developers)

    Fastest: open this repo in GitHub Codespaces (Python and Azure CLI are pre-installed). Or clone it locally. Then:

    Terminal
    cd kit/day1
pip install -r requirements.txt
az login            # in Codespaces: az login --use-device-code

    Copy .env.example to .env and fill in your project endpoint and model deployment name (works the same on Windows, macOS and Linux):

    .env
    FOUNDRY_PROJECT_ENDPOINT=https://<resource>.services.ai.azure.com/api/projects/<project>
FOUNDRY_MODEL=gpt-5.4-mini
    Run
    python chat_app.py
    Error? the app tells you what to fix: not signed in (az login), missing the Azure AI User role on the project, wrong deployment name, or wrong endpoint. Quick fallback for a demo: put the resource's endpoint and API key in .env (option B).

    The app signs in with your Azure identity (no API keys), uses the Responses API, keeps the conversation with previous_response_id and prints token usage, your cost meter. Code: kit/day1/chat_app.py.

🧪 Make it yours: replace Serendib Bank with your own company or a customer use case, rewrite the five rules, and test it with 10 real questions your team gets every week.
Tomorrow's cliffhanger: ask “What's the interest rate on a Serendib Bank home loan?”, it can't know. Day 2 fixes that with grounding.

Clean up

Deployments only cost when called, but delete the resource group when you are done experimenting to keep things tidy.
